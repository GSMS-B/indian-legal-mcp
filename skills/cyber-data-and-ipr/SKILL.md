# 💻 Cyber, Data Privacy, Telecom & IP Law Workflow

## Scope: Which Act Answers What?
| Digital / IP Domain | Applicable Statute | Key MCP Tools |
|---|---|---|
| Cyber Crimes, Hacking & Intermediary Liability | `IT_ACT` (Information Technology Act) | `get_section` (Sec 43, 66, 79) |
| Digital Personal Data Privacy & Consent | `DPDPA` (Data Protection Act, 2023) | `get_section` (Sec 4-10) |
| Aadhaar Identity & Biometric Data | `AADHAAR` Act, 2016 | `get_section` |
| Telecom Networks, Spectrum & Interception | `TELECOM` (Telecommunications Act) | `get_section` |
| Copyright, Fair Dealing & Piracy | `COPYRIGHT` Act, 1957 | `get_section` (Sec 14, 51, 52) |
| Patent Grants, Novelty & Compulsory License | `PATENTS` Act, 1970 | `get_section` (Sec 2, 3, 48, 84) |
| Trademark Registration & Passing Off | `TRADEMARKS` Act, 1999 | `get_section` (Sec 9, 11, 29) |
| Industrial Designs Protection | `DESIGNS` Act, 2000 | `get_section` |
| Geographical Indications of Goods | `GI` Act, 1999 | `get_section` |

## 5-Step Execution Workflow
1. **Differentiate Cyber Offence vs Data Privacy vs IPR:**
   - If unauthorized computer access/data theft: Query `IT_ACT` Section 43/66.
   - If digital processing of personal data, consent, or data breach: Query `DPDPA`.
   - If telecom spectrum or interception: Query `TELECOM`.
   - If brand/creative asset misuse: Query `TRADEMARKS`, `COPYRIGHT`, or `PATENTS`.
2. **Review Intermediary Safe Harbor Requirements:**
   - Under `IT_ACT` Section 79, an intermediary is exempt from liability if it observes due diligence and removes unlawful content upon receiving actual court/government knowledge.
3. **Check DPDPA Compliance Obligations:**
   - Section 6: Specific, informed, unconditional consent notice.
   - Section 8: General obligations of Data Fiduciaries including breach notification to Data Protection Board.
4. **Assess IP Infringement Exceptions:**
   - For Copyright: Check `COPYRIGHT` Section 52 for statutory fair dealing exemptions.
   - For Patents: Check `PATENTS` Section 3 for non-patentable inventions (e.g. 3(d) incremental efficacy, 3(k) computer programs per se).
5. **Synthesize Citations & Provide Exact Provisions:**
   - Deliver clear citations with direct statutory quotes.
